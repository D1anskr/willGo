# willGo 2.0.2：融合器显示

适用于两台电脑通过硬件画面融合器输出到同一台显示器的场景。数据端继续采集本机音频和截图；显示端继续识别、回答和保存记录。新增功能只调整显示端的输出画面。

## 开启方法

1. 在显示端安装 2.0.2，登录后打开“设置 → 双机模式”。
2. 开启双机模式，角色选择“显示端”，按原来的方式完成配对。
3. 在“融合器显示”栏目勾选“遮住桌面，仅保留 willGo”。
4. 先尝试“纯黑”幕布、“深底亮字”、100% 融合不透明度和 22 号字，保存设置。
5. 根据融合器实际的底色过滤方式，切换纯黑或纯白幕布，以及深底亮字、浅底深字、深底黄字三种配色。

融合器显示默认关闭，升级后不会突然遮住桌面。该选项只在显示端生效，数据端和单机模式不启用幕布。

## 显示效果

- 用不透明的纯色幕布覆盖显示端的整个虚拟桌面，包括普通桌面图标、壁纸、任务栏和后方窗口；幕布本身没有任务栏入口。
- willGo 主窗口及其设置、历史等所属窗口位于幕布上方。桌面图标没有被删除，也没有修改系统的壁纸、图标显示或任务栏设置。
- 提供三种高对比配色，覆盖正文、题目、列表、按钮、输入框、行内代码及代码块。融合模式的代码采用统一高对比文字，减少低亮度语法颜色丢失；保留缩进、行号、复制、自动换行和完整展开。
- 融合不透明度默认 100%，答案字号默认 22，与普通模式分别保存。顶部字号按钮与透明度快捷键调整当前模式对应的设置。
- 实时转写区在进入融合模式时默认折叠，让出答案阅读空间；仍可手动展开。退出融合模式会恢复普通模式此前的展开状态。

幕布使用物理像素覆盖整个虚拟桌面，显示器布局变化后重新计算边界。当前机器上的原生窗口覆盖范围已验证；多屏混合缩放及实际硬件融合效果仍需在对应设备上复核。

## 如何恢复桌面

- 点击顶部“退出融合器显示”图标，立即撤下幕布、恢复普通样式，并保存关闭状态；双机连接继续保持。
- 点击“收起窗口”或最小化，暂时撤下幕布；从托盘恢复 willGo 时，按保存的设置重新显示。
- 在设置中取消勾选该选项、关闭双机模式或改为数据端，撤下幕布并恢复普通样式。
- 完全退出 willGo 后，幕布窗口随进程关闭，不需要额外恢复桌面文件或注册表。

鼠标穿透时先按 Ctrl+1 恢复点击，再操作顶部按钮；Ctrl+1 同时作用于主窗口和幕布。数据端转发的快捷键继续可用。

## 硬件边界

GB 融合器存在不同机型和融合设置。照片只能说明两路桌面都混入了画面，无法据此确定设备的色键、亮度阈值或混合比例。软件提供明确的纯色输出和高对比配色，但最终还需匹配设备的设置。

如果白字或黑字被设备滤掉，切换到深底黄字，或调整设备的色键阈值。如果整个 willGo 依然偏淡，需要检查硬件的混合比例；软件中的 100% 不透明度不等同于硬件的 100% 叠加比例。

幕布用于整理普通桌面输出，不隔离系统安全桌面，也不阻止操作系统提示、其他应用的置顶窗口或设备自身画面叠加。

## 验证

覆盖设置保存和旧配置兼容、三种配色的文字对比度、代码换行及展开、原生幕布边界和窗口层级、鼠标穿透、收起与恢复、最小化与恢复、切换角色、关闭及退出。真实应用测试同时验证融合设置不重建双机连接，数据端转发的透明度指令保存至融合设置，退出按钮恢复桌面。

测试使用合成内容和本地服务，不调用用户配置的真实云端接口。未在用户的实体 GB 融合器上验证最终视频输出。
