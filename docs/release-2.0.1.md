# willGo 2.0.1：数据端遥控显示端

基于 2.0.0 局域网双机模式，新增数据端全局快捷键转发。配对方法、音频采集、截图和记录保存方式见 [双机模式说明](release-2.0.0.md)。

## 使用方法

两台电脑均安装 2.0.1 或更新版本，数据端与显示端配对成功后，在数据端使用以下快捷键即可操作显示端。无需将焦点切到 willGo，也无需先开启语音识别。

| 数据端快捷键 | 显示端效果 |
| --- | --- |
| Ctrl + Shift + 上 | 切换到上方较新的问题 |
| Ctrl + Shift + 下 | 切换到下方较旧的问题 |
| Ctrl + 上 / 下 | 向上 / 向下滚动当前答案，每次 120 像素 |
| Ctrl + Shift + 左 / 右 | 降低 / 提高不透明度，每次 5%，范围 30% 至 100%；保存在显示端设置中 |
| Ctrl + 1 | 切换显示端鼠标穿透；白色指示灯为穿透，灰黑色为可点击，再按一次恢复 |
| Ctrl + Shift + S | 按数据端保存的范围截图，传到显示端提取题目并回答；一次按键产生一次截图 |

显示端自己的全局快捷键继续有效。数据端通过托盘菜单切换鼠标穿透时，也会控制显示端；数据端本身保持可点击，便于打开连接设置。未开启双机模式时，快捷键仍操作本机。

数据端保持后台运行；这些操作不会打开它的主窗口，也不会修改它的透明度。显示端需显示主窗口才能看到滚动效果，切题和滚动到列表边界时沿用原来的行为。

## 连接与异常处理

- 操作与音频、截图共用已认证的 TLS 连接，不增加端口或额外配对步骤。
- 连续按键按发送顺序执行，每条操作带序号；显示端不会再次转发收到的操作。
- 断线期间的操作不会缓存；重新连接不会补发旧按键。连接关闭后，尚未执行的界面操作会被丢弃。
- 发送队列拥塞时关闭连接并提示重新连接，避免操作持续积压。正常局域网下可与双路音频和分块截图同时传输；实际响应时间取决于网络情况。
- 2.0.0 与 2.0.1 仍可保持原有音频和截图配对能力，但新快捷键转发需要两端均升级。旧版显示端会触发升级提示。
- 快捷键被其他软件占用时，仍需解决本机的按键冲突；转发只发生在 willGo 实际收到快捷键之后。

## 验证范围

自动化覆盖真实本机 TLS 配对、全部七种界面指令、音频与截图并发时的连续 70 次指令、断线取消、重连无补发、旧版本能力协商，以及真实应用的快捷键回调和显示端窗口效果。语音测试使用本地模拟云服务，不消耗配置中的真实 API。

两台实体电脑的局域网延迟、第三方软件快捷键冲突和防火墙环境仍需在实际配对环境中验证。
