# willGo 1.10.4

The login window uses a rounded white frame with a green accent, an embedded
window/morning-light/steps drawing and supportive Chinese copy for job seekers.
The drawing is a native WPF resource and requires no downloads or network access.

The account input, remember option, status messages, Enter-to-login behavior and
close action remain available. Window dimensions are constrained to the desktop
work area and the body scrolls on shorter screens. Authentication, fixed local
access, capture exclusion and taskbar visibility behavior are preserved.
