# willGo 1.10.2

Code blocks automatically wrap long lines to the available width, including
unbroken identifiers and comments. They have no internal horizontal or vertical
scrollbars and expand to display every wrapped line. Resizing the window or
dragging the question/answer divider recalculates wrapping and height.

Syntax highlighting, line numbers, selection and copy controls remain available.
Wrapping only affects display: copied code preserves its original whitespace and
physical line breaks. Existing settings and credentials are preserved.
